# VFX & advertising news feeds

Atom feeds regenerated every two hours from **Little Black Book**, **Shots** and **Campaign UK**.
Each entry carries the headline, featured image, the publisher's own summary and the credits
we could extract (brand, agency, creative director, production company, director, post/VFX).
Full articles stay on the publishers' sites; the feeds only link to them.

| Feed | URL |
|---|---|
| LBB | `lbb.xml` |
| Shots | `shots.xml` |
| Campaign UK | `campaign.xml` |
| Everything | `all.xml` |
| OPML | `vfx-news-feeds.opml` |

Generated by a private script; this repository only hosts the output.
